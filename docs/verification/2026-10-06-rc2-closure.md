## Bounded measurement

Fixture: `tests/Distribution/benchmark.php`; one warmup and five measured passes
over 1,000 deterministic requests and 1,000 indexed rows. MySQL/PostgreSQL ran
as separate servers; SQLite used memory as a fast reference.
Redis 8.10.2 ran separately with AOF, `appendfsync always` and `noeviction`.
All results matched ground truth; rollback/pre-added false positive fell back
to SQL correctly. No artificial datastore latency or concurrent traffic.

was measured in the emitted JSON separately

controlled; these numbers prove bounded measurements, not a speedup claim.

Active writers remained zero. Drain reads use Redis only; labels identify
separate sequential runs, not a datastore dependency.

The performance conclusion is explicit: SQL query avoidance works, but these
local indexed datastores are cheaper than the Redis gate in all observed
workloads. Long-lived retained history raises drain cost. Target workloads need
their own measurements. MongoDB integration was not tested.
