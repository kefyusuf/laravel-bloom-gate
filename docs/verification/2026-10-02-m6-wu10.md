  `readActiveLeases()` operation. All became green after implementation.

  abort drain, and persisted retirement states have explicit classification tests.
- Ownership/config disagreement, missing synchronization, impossible target/drain
  relations, corrupt storage, and unavailable count observations are covered.
- Mock mutation expectations and persisted snapshot comparisons establish
  read-only behavior.
- The same lease inspection contract runs on Memory and live Redis. It preserves
  original epoch/target bindings, distinguishes A/P, excludes R, keeps counters
  unchanged, and integrates with the optional status reader.
- A live malformed Redis lease registry is rejected without repair.
- Deliberately differing enumeration and writer-count observations demonstrate
  that enumeration does not replace the persisted drain count.
- Existing architecture, lifecycle, query-safety, writer, rebuild, recovery, and
  Laravel tests remained green.
