# Laravel Bloom Gate v0.1.0-rc.2

Second evaluation release candidate. This is not a stable v1 release or a
production deployment certification. The first candidate remains immutable.

## Changes since rc.1

- Writer drain reads reject inconsistent surviving lease/count evidence in
  Memory and Redis without repairing it.
- Production-only Redis with MySQL, PostgreSQL and SQLite consumers verifies trusted negatives,
  authoritative fallback, known SQL commit/rollback outcomes and rebuild.
- Executable README setup includes a complete immutable filter example and
  distinguishes legacy pre-add from coordinated prepared writes.
- The candidate pilot now installs the exact selected source commit and emits
  bounded query and retained-lease measurements.

## Performance and operational boundaries

Query avoidance is workload-dependent. In the local 1,000-query absent-value
workload, SQL queries fell from 1,000 to 8. The Redis gate was slower than the
indexed local MySQL, PostgreSQL and in-memory SQLite baseline; this is not
evidence of a general latency improvement.
All-present queries avoided no SQL calls. Measure the target application's
datastore and negative-query ratio before enabling optimization for performance.

Writer drain validation scans retained lease history. The local median grew
from about 0.16–0.20 ms with no retained leases to 2.33–2.86 ms with 1,000 released leases.
These are bounded development measurements, not production throughput limits.

PHP 8.3+ and Laravel 12/13 remain the supported runtime targets. Redis trusted
negatives require the documented durable standalone-primary profile; every
membership-entry writer for a coordinated mutable filter must participate in
the prepared-write protocol. Recovery still requires authoritative evidence.
Redis Cluster, unobserved production deployments and long-running retained
history are not certified by this candidate. MongoDB integration is unverified.
SQL comparison/collation must agree with the filter's normalization semantics.

## Installation after publication

```sh
composer require kefyusuf/laravel-bloom-gate:0.1.0-rc.2
php artisan vendor:publish --tag=bloom-gate-config
```

Packagist registration, indexing and remote installation must be observed
separately from a GitHub tag. See the closure verification record for exact
candidate CI and publication evidence.
